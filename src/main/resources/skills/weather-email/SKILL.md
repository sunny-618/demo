# 任务目标
根据用户提供的用户ID（userId），查询该用户的地址，获取当地天气，并发送一封贴心的天气提醒邮件。

# 执行步骤（请严格按照以下顺序执行）：
1. **查询用户信息**：首先，调用 `executeSelectQuery` 工具，传入用户提供的 `userId`，获取该用户的姓名（userName）、地址（address）和邮箱（email）。
    - *注意：如果查不到该用户信息，请直接终止流程，并回复“未找到该用户的档案，无法发送天气提醒”。*
2. **查询天气信息**：其次，调用 `getWeather` 工具，传入第一步获取到的地址（address），查询当地天气。
3. **生成穿衣建议**：然后，根据查到的天气信息，结合用户的姓名（userName），生成一段亲切、连贯的穿衣建议。
4. **发送提醒邮件**：最后，调用 `sendEmail` 工具，将第一步获取的邮箱（email）作为收件人，标题设为“今日天气提醒”，正文设为上一步生成的穿衣建议发送出去。
    - *注意：如果第一步没有获取到邮箱（为空），请直接提示“该用户未绑定邮箱，无法发送”，并终止流程。*

# 注意事项
- 请务必确保每一步都成功后再执行下一步。
- 如果查不到用户信息，直接终止并告知“未找到档案”。
- 如果邮箱为空，提示“未绑定邮箱”，不要发邮件。
- 发送邮件时，内容请排版清晰，可以包含 Emoji（如 ☀️、🌡️、👕）增加亲和力。
